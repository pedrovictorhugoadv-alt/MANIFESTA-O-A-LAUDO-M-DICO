# Victor Hugo Advogados — Repositório do Escritório

Repositório privado com configurações, skills e documentos do escritório Victor Hugo Advogados (Serra Talhada/PE).

## Estrutura

```
victor-hugo-advogados/
├── skills/                        # Skills do assistente jurídico (Cowork/Claude)
│   ├── manifestacao-laudo.skill   # Geração de manifestações ao laudo pericial
│   └── manifestacao-laudo-v2.skill
├── documentos/                    # Peças jurídicas geradas
│   └── *.docx
├── get-shit-done/                 # Framework de produtividade para Claude Code
└── review_iteration1.html         # Revisão de iteração
```

## Skills

As skills `.skill` são instaladas no Claude Cowork para automatizar a geração de peças previdenciárias no padrão do escritório.

## Uso

Clone o repositório e instale as skills conforme a documentação do Claude Cowork.
